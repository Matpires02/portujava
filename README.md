# 🚀 PortuJava

Ferramenta para auxílio a alunos. Auxilia a passagem da linguagem Portugol para java. Criado para o TCC da faculdade de Sistemas de Informação no IFMG.

Disponível no site: `https://portujava.vercel.app`

## 🧠 Sobre o projeto
O PortuJava permite converter códigos escritos em Portugol para Java, abordando as diferenças de sintaxe e de idioma — situação comumente enfrentada por alunos que entram em contato com linguagens profissionais. A ferramenta é disponibilizada como uma aplicação web, desenvolvida com o framework Angular, e utiliza o plugin JDoodle IDE para visualização e execução dos códigos em Java.

## 🚀 Tecnologias
- Angular
- TypeScript
- HTML5
- CSS3
- Git

## 📌 Funcionalidades
- Transposição de códigos, completos ou partes, em Portugol (Portugol Studio ou Visualg)
- Donwload do código JAVA gerado
- Interface web responsiva
- Componentes reutilizáveis
- Navegação entre páginas

## ▶️ Como rodar

### Clone o repositório
git clone https://github.com/Matpires02/portujava.git

### Instale as dependências
npm install

### Execute o projeto
ng serve

📍 O frontend estará disponível em:
http://localhost:4200
